# Train Ticket Booking Simulator

A Python-based Train Ticket Booking Simulator that allows users to search trains, book tickets, view bookings, and cancel tickets.

## Features

- View available trains
- Search trains by source and destination
- Book train tickets
- Manage passenger details
- Track available seats
- Calculate total fare
- View all bookings
- Cancel tickets
- Automatic seat management

## Technologies

- Python
- Dictionaries
- Lists
- Functions
- Loops
- Exception Handling

## How to Run

python train_ticket_booking.py

## Concepts Used

- Dictionary
- Functions
- Conditional statements
- Loops
- Input validation
- Exception handling
- Data management

## Purpose

This project helps practice Python data structures, functions, user input, validation, and basic booking-system logic.
